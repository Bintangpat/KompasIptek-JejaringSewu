## 1. Alasan Pengembangan
Perbaikan dilakukan untuk menyelesaikan *fatal runtime exception* `Invariant Violation: ScrollView child layout (["justifyContent"]) must be applied through the contentContainerStyle prop` pada formulir autentikasi. Bersamaan dengan itu, dibangun alur inisiasi aplikasi terpadu (*Splash Screen* berbasis animasi Lottie adaptive dark/light mode $\rightarrow$ *Information Screen* 3 slide edukasi fitur $\rightarrow$ Dashboard Komuter Tamu / Autentikasi) guna meningkatkan retensi pengguna baru dan memenuhi standar *enterprise user onboarding*.

## 2. Pengembangan Fitur & Mekanisme Teknis

### 2.1 Resolusi Invariant Violation pada ScrollView Autentikasi
- **Tujuan Teknis:** Mencegah aplikasi crash di Android/iOS ketika merender halaman login dan OTP akibat properti child layout (`justifyContent`) diterapkan langsung pada wrapper `ScrollView` melalui utilitas Uniwind/Tailwind.
- **Mekanisme & Alur Kerja:**
  - Menghapus kelas `justify-center` dari `className="p-5 justify-center"` pada komponen `<ScrollView>`.
  - Memindahkan instruksi perataan vertikal ke prop bawaan `contentContainerStyle={{ flexGrow: 1, justifyContent: 'center' }}`.
  - Memastikan konten formulir tetap terpusat secara vertikal di layar namun fleksibel mengikuti tinggi viewport dan keyboard.
- **Berkas Terkait:**
  - [`Mobile2/app/(auth)/login.tsx`](file:///D:/Projects/KompasIptek/Mobile2/app/(auth)/login.tsx): Perbaikan prop ScrollView pada form login.
  - [`Mobile2/app/(auth)/otp.tsx`](file:///D:/Projects/KompasIptek/Mobile2/app/(auth)/otp.tsx): Perbaikan prop ScrollView pada form verifikasi OTP.

### 2.2 Splash Screen Lottie dengan Dynamic Color Theming
- **Tujuan Teknis:** Menyajikan splash screen interaktif menggunakan animasi Lottie (`Docs/Design/Android_Compact_-_1.json`) dengan adaptasi warna otomatis sesuai preferensi tema perangkat pengguna.
- **Mekanisme & Alur Kerja:**
  - Mengintegrasikan library `lottie-react-native`.
  - Membaca skema warna pengguna secara reaktif via `useColorScheme()`.
  - **Transformasi JSON In-Memory (`themedSource`):**
    - **Mode Gelap (`isDark === true`):** Mengubah *fill color* layer background `Android Compact - 1 Bg` menjadi warna hitam pekat `[0, 0, 0]` dan memetakan *fill keyframe* teks `Jejaring Sewu` menjadi putih `[1, 1, 1]`.
    - **Mode Terang (`isDark === false`):** Mengubah *fill color* background menjadi putih `[1, 1, 1]` dan teks menjadi hitam `[0, 0, 0]`.
  - Menjalankan autoPlay hingga animasi tuntas (`onAnimationFinish`) atau batas timeout fallback 2,8 detik, lalu mengevaluasi sesi autentikasi dan status onboarding.
- **Berkas Terkait:**
  - [`Mobile2/assets/animations/splash.json`](file:///D:/Projects/KompasIptek/Mobile2/assets/animations/splash.json): Berkas asset JSON Lottie animasi identitas visual pekon.
  - [`Mobile2/app/index.tsx`](file:///D:/Projects/KompasIptek/Mobile2/app/index.tsx): Layar gerbang inisialisasi aplikasi (Splash Screen).

### 2.3 Information Screen 3 Slide (Onboarding Flow)
- **Tujuan Teknis:** Mengedukasi pengguna baru mengenai 3 pilar ekonomi kerakyatan Pekon (Nebeng-Jastip Searah, Bursa Panen & Mini-Job Zero-Discrimination, serta Selfie PoW & Skor Kredit BUMDes).
- **Mekanisme & Alur Kerja:**
  - Menggunakan `FlatList` horizontal dengan `pagingEnabled` untuk navigasi slide yang mulus via sentuhan maupun tombol kontrol.
  - **Struktur Kontrol Halaman 1 & 2 (Slide Index 0 & 1):**
    - Sisi kiri bawah: Tombol *"Sebelumnya"* (disembunyikan pada slide pertama, aktif pada slide kedua).
    - Sisi kanan bawah: Tombol *"Selanjutnya"* bertipe `primary` untuk beralih ke slide berikutnya.
  - **Struktur Kontrol Halaman 3 (Slide Terakhir / Index 2):**
    - Tombol *"Selanjutnya"* **menghilang**.
    - Tombol *"Sebelumnya"* tetap aktif berada di **sisi kiri bawah** dalam baris terpisah sehingga **tidak tertutupi**.
    - Di bawah tombol Sebelumnya, tersedia 2 tombol bersebelahan secara horizontal:
      - `[ Lewati ]` (variant `outline`, flex-1): Menandai onboarding selesai dan mengarahkan langsung ke dashboard utama `/(tabs)/commuter` dalam mode tamu.
      - `[ Daftar ]` (variant `primary`, flex-1): Menandai onboarding selesai dan membuka halaman registrasi `/(auth)/register`.
    - Tautan pintasan *"Sudah memiliki akun warga? Masuk di sini"* mengarahkan ke form login.
- **Berkas Terkait:**
  - [`Mobile2/app/information.tsx`](file:///D:/Projects/KompasIptek/Mobile2/app/information.tsx): Komponen lengkap onboarding 3 slide dengan PanelUI.

### 2.4 Registrasi Kunci Penyimpanan Onboarding
- **Tujuan Teknis:** Menyimpan status penyelesaian onboarding secara persisten dan aman agar pengguna tidak perlu melihat kembali slide informasi pada peluncuran aplikasi berikutnya.
- **Mekanisme & Alur Kerja:**
  - Menambahkan key `ONBOARDING_COMPLETED: 'jejaring_sewu_onboarding_completed'` pada objek `STORAGE_KEYS`.
  - Disimpan menggunakan `expo-secure-store` pada Android/iOS dan fallback `localStorage` pada Web.
- **Berkas Terkait:**
  - [`Mobile2/services/secure-storage.ts`](file:///D:/Projects/KompasIptek/Mobile2/services/secure-storage.ts): Definisi kunci storage persisten.
  - [`Mobile2/app/_layout.tsx`](file:///D:/Projects/KompasIptek/Mobile2/app/_layout.tsx): Pembaruan stack router dengan anchor `index` dan pendaftaran layar `index` serta `information`.

## 6. Prosedur Rollback
Jika ditemukan kendala kompatibilitas runtime pada perangkat tertentu:
1. Kembalikan anchor `Mobile2/app/_layout.tsx` ke `(tabs)`.
2. Hapus layar `Mobile2/app/index.tsx` dan `Mobile2/app/information.tsx`.
3. Kembalikan konfigurasi `ScrollView` di `login.tsx` dan `otp.tsx` (namun tetap pertahankan `justifyContent` di `contentContainerStyle`).
