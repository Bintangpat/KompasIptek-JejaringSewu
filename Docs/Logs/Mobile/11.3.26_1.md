## 1. Alasan Pengembangan
> **Catatan Penting:** Bagian ini HARUS SINGKAT (maksimal 2–3 kalimat langsung pada inti masalah/kebutuhan bisnis).

Menghapus tampilan *AI slop* dengan menstandardisasi design system native berbasis **PanelUI** (Tailwind CSS v4 & Uniwind), memperbaiki bug overlay bottom sheet yang melar ke atas layar menjadi dinamis sesuai tinggi konten, serta mengimplementasikan middleware **Auth Wall Sheet** agar pengguna tamu (guest mode) dapat menjelajah aplikasi tanpa terblokir sebelum melakukan transaksi kritis.

### 2.3 Alur Autentikasi & Middleware Auth Wall Sheet (Solusi Masalah #1)
- **Tujuan Teknis:** Menyediakan alur `Splash Screen -> Cek Sesi (Auth) -> OTP -> Halaman Utama` yang profesional, serta mengintersep aksi transaksi kritis pengguna tamu tanpa memblokir penjelajahan publik (guest browsing).
- **Mekanisme & Alur Kerja:**
  - `SplashScreen.preventAutoHideAsync()` dipanggil pada inisialisasi root `_layout.tsx`, memulihkan token JWT dan profil dari `expo-secure-store`, lalu mengeksekusi `SplashScreen.hideAsync()`.
  - Pembuatan modul autentikasi PanelUI:
    - `app/(auth)/login.tsx`: Form login berbasis PanelUI `Card`, `Input`, `Button`, tombol Demo Login Pak Slamet (Petani), dan opsi "Jelajahi Dulu (Mode Tamu)".
    - `app/(auth)/register.tsx`: Registrasi warga desa dengan validasi NIK 16 digit Zod dan Switch inklusif disabilitas.
    - `app/(auth)/otp.tsx`: Verifikasi OTP menggunakan `OtpInput` 6 digit dengan countdown resend.
  - Pembuatan hook `useAuthProtection()` dan komponen reusable `AuthWallSheet`:
    - Memotong aksi kritis seperti: *Buka Rute Perjalanan*, *Titip Barang Jastip*, *Ambil & Kunci Tugas Mini-Job*, *Pasang Panen*, *Tawar Harga Panen*, *Jepret Kamera Selfie PoW*, dan *Klaim Modal BUMDes*.
    - Jika user belum login, sheet muncul dari bawah menampilkan pesan edukatif, tombol primer *"Masuk / Daftar Akun Warga"* (mengarahkan ke `/(auth)/login`), dan tombol sekunder *"Nanti Dulu"* (menutup sheet tanpa force logout).
- **Berkas Terkait:**
  - [`Mobile2/app/_layout.tsx`](file:///D:/Projects/KompasIptek/Mobile2/app/_layout.tsx): Root layout pembungkus `<PanelUIProvider>`, splash screen controller, dan routing stacks.
  - [`Mobile2/components/ui/auth-wall-sheet.tsx`](file:///D:/Projects/KompasIptek/Mobile2/components/ui/auth-wall-sheet.tsx): Bottom sheet intersep autentikasi.
  - [`Mobile2/hooks/use-auth-protection.ts`](file:///D:/Projects/KompasIptek/Mobile2/hooks/use-auth-protection.ts): Hook proteksi aksi berbasis status sesi Zustand `useAuthStore`.

## 5. Kontrak API & Potensi Breaking Changes
- **Endpoint Terkait:**
  - `POST /api/v1/auth/login`: Mengirimkan payload `{ identifier, password, deviceId }`.
  - `POST /api/v1/auth/register`: Mengirimkan registrasi NIK 16 digit.
  - `POST /api/v1/auth/otp/verify`: Mengirimkan `{ identifier, otpCode }`.
- **Status Kompatibilitas:** 100% Backward Compatible dengan kontrak backend NestJS.

---

## 6. Keamanan, Integritas Data & Validasi
- **Penyimpanan Sesi Kredensial:** Akses token JWT dan refresh token disimpan terenkripsi di `expo-secure-store`.
- **Pencegahan Pemalsuan Bukti PoW:** Fitur kamera memvalidasi hash SHA-256 secara langsung pada thread perangkat dan memverifikasi koordinat GPS (toleransi ≤50m) sebelum transaksi diserahkan ke buku besar pekon.
- **Proteksi Akses Aksi:** Pengguna guest dicegah memicu mutasi dompet dan buku besar tanpa sesi akun warga yang sah.
