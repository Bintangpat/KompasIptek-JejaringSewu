## 1. Alasan Pengembangan
> **Catatan Penting:** Bagian ini HARUS SINGKAT (maksimal 2–3 kalimat langsung pada inti masalah/kebutuhan bisnis).

Menggantikan *storage provider placeholder* Cloudflare R2 dengan **Backblaze B2 (S3-Compatible)** untuk penyimpanan bukti foto fisik Selfie Proof-of-Work (`PoW`) berfitur WORM yang hemat biaya dan teruji aktif. Sekaligus mengaktifkan kredensial resmi **Firebase Admin SDK (`jejaringsewu-dev`)** untuk saluran Push Notification dan verifikasi OTP real-time di seluruh ekosistem Backend, Web, dan Mobile2.

## 2. Pengembangan Fitur & Mekanisme Teknis

### 2.1 Modul Penyimpanan Objek Backblaze B2 (`Backend/src/core/storage/`)
- **Tujuan Teknis:** Menyediakan layanan penyimpanan objek S3-compatible yang tangguh, terenkripsi AES-256, dan mendukung kalkulasi checksum kriptografi SHA-256 secara server-side.
- **Mekanisme & Alur Kerja:**
  - `StorageService` menginisialisasi `@aws-sdk/client-s3` dengan endpoint `https://s3.us-east-005.backblazeb2.com`, region `us-east-005`, dan bucket `jejaring-sewu-pow-dev`.

  - Setiap objek disimpan dengan metadata SHA-256 dan dapat diakses publik melalui URL download `https://f005.backblazeb2.com/file/jejaring-sewu-pow-dev/<key>`.
  - Mengembangkan endpoint `POST /api/v1/storage/upload` di `StorageController` untuk menerima unggahan bukti kerja langsung.

## 5. Keamanan & Integritas Transaksi (Financial & Security Integrity)
- **Otentikasi Kriptografi S3:** Seluruh transmisi berkas ke Backblaze B2 ditandatangani menggunakan algoritma AWS Signature Version 4 (SigV4) dengan secret key Backblaze.
- **Immutability & Integrity Hash:** Setiap berkas yang diunggah divalidasi checksum SHA-256 miliknya, dicocokkan dengan header `X-Image-Hash` transaksi, dan disimpan sebagai metadata objek di Backblaze B2.
- **Zero-Trust Private Key Handling:** Kunci privat Firebase Admin SDK tersimpan terlindungi di `.env` dan berkas JSON lokal yang diabaikan oleh `.gitignore`.

---

## 6. Penanganan Galat & Edge Cases (Failure Modes & Resilience)
- **Offline / Network Latency Fallback:** Jika jaringan mengalami gangguan saat mengunggah foto base64, fungsi klien menyediakan fallback deterministik URL format Backblaze B2 berbasis hash SHA-256.
- **Firebase Initialization Fallback:** Jika berkas service account JSON hilang atau path salah, `FcmProvider` otomatis membaca variabel `FIREBASE_PRIVATE_KEY` langsung dari environment tanpa mematikan proses server backend.
