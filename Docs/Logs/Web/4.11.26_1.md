## 2. Pengembangan Fitur & Mekanisme Teknis

### 2.1 Pemasangan & Integrasi Keluarga Huruf Geist
- **Tujuan Teknis:** Mengintegrasikan paket font resmi Vercel `geist` (`GeistSans` dan `GeistMono`) dengan variabel CSS Next.js agar seluruh halaman web mewarisi keterbacaan tinggi di berbagai resolusi layar.
- **Mekanisme & Alur Kerja:**
  - Menginstal dependensi resmi `geist` pada `Web/package.json`.
  - Mengimpor `GeistSans` dari `geist/font/sans` dan `GeistMono` dari `geist/font/mono` pada `Web/src/app/layout.tsx`.
  - Menyuntikkan kelas variabel `GeistSans.variable` (`--font-geist-sans`) dan `GeistMono.variable` (`--font-geist-mono`) ke elemen `<html>`.
  - Mengonfigurasi `Web/tailwind.config.js` untuk memetakan `fontFamily.sans` dan `fontFamily.mono` dengan hierarki variabel Geist sebagai prioritas pertama diikuti *system fallback*.
  - Mendeklarasikan `--font-sans` dan `--font-mono` di dalam `@theme inline` pada `Web/src/app/globals.css`.
- **Berkas Terkait:**
  - [`Web/src/app/layout.tsx`](file:///D:/Projects/KompasIptek/Web/src/app/layout.tsx): Pemasangan provider font GeistSans dan GeistMono pada RootLayout.
  - [`Web/tailwind.config.js`](file:///D:/Projects/KompasIptek/Web/tailwind.config.js): Pemetaan token font Tailwind CSS.
  - [`Web/src/app/globals.css`](file:///D:/Projects/KompasIptek/Web/src/app/globals.css): Deklarasi CSS inline variables `@theme` dan token warna OKLCH.

### 2.2 Penyusunan Dokumen Spesifikasi Desain Terpadu (`DESIGN.md`)
- **Tujuan Teknis:** Menyediakan pedoman desain sistem komprehensif berstandar enterprise bagi seluruh pengembang frontend di subproject Web.
- **Mekanisme & Alur Kerja:**
  - Mendokumentasikan hierarki tipografi lengkap (Display, Headings, Body Text, Muted Text, Data Finansial, dan Kripto/Geospasial).
  - Merinci token warna berbasis ruang warna OKLCH untuk tema gelap (`.dark`) dan tema terang (`:root`).
  - Memetakan palet spesifik pedesaan `pekon` (`#0F1416`, `#151C1E`, `#00F2A9`, dll.) dan skala `brand` emerald.
  - Menjelaskan arsitektur tata letak: *Provider Tree* (`ThemeProvider`, `AuthProvider`, `TooltipProvider`, `Toaster`), tinggi header (`3.5rem`), radius sudut (`rounded-sm` hingga `rounded-xl`), dan pedoman aksesibilitas WCAG 2.1 AA.
- **Berkas Terkait:**
  - [`Web/DESIGN.md`](file:///D:/Projects/KompasIptek/Web/DESIGN.md): Berkas dokumentasi utama desain sistem.

- **Perintah Eksekusi:** `npx tsc --project Web/tsconfig.json --noEmit`

- Indikator fokus `focus-visible:ring-ring` aktif di seluruh elemen interaktif tombol dan input.

## 6. Prosedur Rollback

Jika ditemukan ketidakcocokan visual pada peramban web lawas:
1. Kembalikan impor font di `Web/src/app/layout.tsx` ke `next/font/google` (`Inter`).
2. Hapus referensi variabel `var(--font-geist-sans)` dan `var(--font-geist-mono)` di `Web/tailwind.config.js`.
3. Jalankan kembali `npx tsc --project Web/tsconfig.json --noEmit` untuk memastikan stabilitas kompilasi.
