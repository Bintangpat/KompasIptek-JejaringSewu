## 2. Pengembangan Fitur & Mekanisme Teknis

### 2.1 Lapisan Klien Inti, Keamanan & Utilitas (`Web/src/lib/` & `Web/src/types/`)
- **Tujuan Teknis:** Menyediakan fondasi komunikasi HTTP yang tahan gangguan (*fault-tolerant*), anti serangan XSS/Replay, serta mendukung penanganan kriptografis bukti kerja di sisi peramban.
- **Mekanisme & Alur Kerja:**
  - **In-Memory JWT & Silent Refresh Mutex:** Token sesi disimpan murni di memori JavaScript (tanpa `localStorage`) dan saat terjadi respons `401 Unauthorized`, interceptor mengeksekusi rotasi token tunggal (*single-flight mutex*) via HttpOnly Cookie `jejaring_pringsewu` ke `POST /auth/refresh`.
  - **Auto-Injection Idempotency-Key:** Setiap mutasi finansial (`POST`, `PATCH`, `DELETE`) secara otomatis disematkan header `X-Idempotency-Key` (UUIDv4) untuk mencegah transaksi berulang akibat fluktuasi sinyal internet desa.
  - **Kalkulasi Biner Hash SHA-256:** Utilitas [`crypto.ts`](file:///D:/Projects/KompasIptek/Web/src/lib/crypto.ts) menggunakan Web Crypto API `window.crypto.subtle.digest` untuk menghitung checksum SHA-256 berkas foto secara nyata sebagai nilai header `X-Image-Hash`.
  - **Stempel Watermark Geospasial Kanvas:** Utilitas [`geo-watermark.ts`](file:///D:/Projects/KompasIptek/Web/src/lib/geo-watermark.ts) membakar (*burn-in*) koordinat GPS, timestamp WIB, nama Pekon, dan identitas aktor langsung pada piksel kanvas 2D sebelum dikonversi menjadi Blob JPEG.
  - **Strict Type System:** [`types/index.ts`](file:///D:/Projects/KompasIptek/Web/src/types/index.ts) diselaraskan 100% dengan skema Prisma dan DTO NestJS (`Role`, `VulnerabilityStatus`, `TransactionType`, `TransactionStatus`, `CreditGrade`, `ApiResponse<T>`, `ApiError`).
- **Berkas Terkait:**
  - [`Web/src/lib/api-client.ts`](file:///D:/Projects/KompasIptek/Web/src/lib/api-client.ts): Klien Axios terenkapsulasi dengan interceptor cerdas dan error mapping.
  - [`Web/src/lib/crypto.ts`](file:///D:/Projects/KompasIptek/Web/src/lib/crypto.ts): Utilitas kalkulasi hash SHA-256 biner klien.
  - [`Web/src/lib/geo-watermark.ts`](file:///D:/Projects/KompasIptek/Web/src/lib/geo-watermark.ts): Engine pembubuh stempel metadata ke kanvas gambar.
  - [`Web/src/types/index.ts`](file:///D:/Projects/KompasIptek/Web/src/types/index.ts): Definisi antarmuka TypeScript terpadu.

## 6. Keamanan, Integritas Data & Validasi

- **Otorisasi Ketat Berbasis Peran:** Seluruh endpoint otoritas baru dilindungi oleh kombinasi `JwtAuthGuard`, `RolesGuard`, dan metadata `@Roles(...)`. Warga biasa yang mencoba memanggil endpoint admin otomatis ditolak dengan `403 Forbidden`.
- **Integritas Buku Besar Double-Entry:** Setiap mutasi dompet buku besar (`LedgerEntry`) dihitung tanda tangan integritas HMAC-SHA256 (`CryptoService.generateLedgerSignature`). Endpoint `/transactions/audit-trail` secara real-time membandingkan tanda tangan di database dengan tanda tangan hash kriptografis terkini.
- **Validasi Input DTO:** Menggunakan pustaka `class-validator` (`IsUUID`, `IsInt`, `Min`, `IsOptional`, `Type`) untuk memastikan integritas input body sebelum diproses ke controller/service.
- **Anti-Fraud Selfie PoW:** Bukti kerja hanya diterima jika `isCameraDirect == true` dengan metadata geolocation yang cocok di wilayah pekon bersangkutan.

## 8. Strategi Rollback & Mitigasi Risiko (Disaster Recovery)

- **Langkah Rollback Kode:** Jika ditemukan anomali tak terduga, kembalikan commit terkait menggunakan:
  ```bash
  git checkout HEAD~1 -- Web/src/ Backend/src/
  ```
- **Langkah Rollback Data:** Karena tidak ada migrasi destruktif pada basis data PostgreSQL, tidak diperlukan down-migration skema database. Status pinjaman dan antrean paket gizi memiliki status state-machine yang dapat dinormalisasi kembali secara manual melalui Prisma Studio jika terjadi *human-error* pada operator BUMDes.
- **Mitigasi Risiko:** Seluruh hooks di `Web/src/hooks/` dilengkapi mekanisme *graceful fallback* ke mock data lokal. Jika koneksi jaringan terputus atau server backend dalam status maintenance, antarmuka web tetap dapat diakses dan tidak mengalami layar putih (*white screen of death*).
