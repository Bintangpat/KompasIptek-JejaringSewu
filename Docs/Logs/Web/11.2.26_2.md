## 2. Pengembangan Fitur & Mekanisme Teknis

### 2.1 Halaman Manajemen Pengguna (`Web/src/app/super-admin/users/page.tsx`)
- **Tujuan Teknis:** Menyediakan antarmuka visual komprehensif bagi Super Admin untuk audit pengguna, pembaruan atribut esensial, dan penonaktifan akun secara aman.
- **Mekanisme & Alur Kerja:**
  - **Tabel Data Interaktif:** Menyajikan daftar pengguna dengan pencarian real-time (nama, nomor telepon, email, referral code), filter peran (*Role*), filter wilayah (*Pekon*), dan filter status operasional (*Aktif* vs *Nonaktif*).
  - **Edit Data Pengguna:** Modal dialog interaktif untuk mengubah nama, email, peran, pekon, status verifikasi NIK fisik, flag kerentanan inklusi, dan status akun.
  - **Soft Delete Modal:** Dialog konfirmasi peringatan berstandar kepatuhan perbankan/ledger yang menjelaskan bahwa penghapusan tidak merusak integritas buku besar dompet dan bukti kerja Selfie PoW.
  - **Ekspor CSV Instan:** Mengonversi data pengguna yang sedang difilter menjadi berkas `.csv` terformat dan mengunduhnya ke perangkat klien.
  - **Backup Snapshot:** Menghasilkan arsip `.json` terstruktur berisikan metadata dan data pengguna berstempel waktu untuk kebutuhan cadangan darurat.
  - **Impor Data Pengguna Baru:** Form penerima teks/berkas CSV atau JSON dengan algoritma deteksi tabrakan identitas. Jika NIK, nomor WhatsApp, atau email sudah terdaftar di database, baris tersebut secara otomatis dilewati (*skipped*).
  - **Pop-up Rangkuman Impor:** Modal pelaporan transparan yang menampilkan kartu statistik (Jumlah Berhasil Dibuat vs Jumlah Baris Dilewati) serta tabel rincian baris yang dilewati lengkap dengan nomor baris, nama, identifier, dan alasan penolakan.
